<summary><b>📌 O que é Vibecoding? (clique)</b></summary>

<br/>

**Vibecoding** é alavancagem aplicada ao desenvolvimento: combinar boas práticas com ferramentas modernas (especialmente IA) para entregar valor com velocidade.

**Princípios que eu sigo:**
- 🎯 **Problema primeiro**: entender, recortar e validar antes de codar demais
- 🤖 **IA como amplificador**: revisar, gerar rascunhos, testar hipóteses, documentar
- ⚡ **Iteração rápida**: protótipo → feedback → melhoria
- 🧩 **Sistemas simples**: menos mágica, mais previsibilidade
